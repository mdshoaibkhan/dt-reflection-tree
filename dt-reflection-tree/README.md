# Daily Reflection Tree

## Overview
This project is a deterministic reflection tool that guides users through structured end-of-day thinking using a decision tree.

## Axes Covered
1. Locus (Victim vs Victor)
2. Orientation (Contribution vs Entitlement)
3. Radius (Self vs Others)

## Approach
The system is fully deterministic:
- Fixed questions
- Fixed options
- Predefined branching
- No AI at runtime

## AI Usage
Used AI tools (ChatGPT) to:
- Explore psychological frameworks
- Improve question phrasing
- Refine reflection statements

Final structure and logic were manually designed.
